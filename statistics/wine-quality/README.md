# Statistical Modeling of Wine Quality

This team project studies which physicochemical measurements distinguish quality groups. The R analysis combines exploratory graphics, principal component analysis, logistic regression and a random forest.

## Explore the project

| File | What it contains |
| --- | --- |
| [Integrated R analysis](analysis/wine-quality.R) | Preprocessing, visualization, principal components and modeling. |
| [Wine measurements](data/WineQT.csv) | Physicochemical features and observed quality labels. |
| [Team presentation (Chinese)](report/wine-quality.pdf) | Results and interpretation of the wine quality analysis. |

## Data and use

The archived R source refers to its original local data path. The corresponding input is included under data/WineQT.csv.
