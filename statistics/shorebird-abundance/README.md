# Estimating Shorebird Nest Abundance with Double Sampling

Rapid surveys cover more plots than intensive nest searches. This team study uses plots observed by both methods to estimate total nests. Haifei Yang was responsible for the empirical sampling results.

## Explore the project

| File | What it contains |
| --- | --- |
| [Two-phase ratio estimator](analysis/two-phase-estimator.R) | Uses the paired subsample to calibrate the rapid-survey total. |
| [Plot observations](data/shorebirds.csv) | Rapid and intensive counts used in the estimator. |
| [Sampling design (Chinese)](report/sampling-design.pdf) | Case background, sampling design and statistical reasoning. |

## Data and use

The team study draws on Bart and Earnst (2002), Double Sampling to Estimate Density and Population Trends in Birds. The R file retains its original input path.
