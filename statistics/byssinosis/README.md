# Occupational Exposure and Byssinosis

An individually authored UC Davis STA 138 project analyzes grouped disease counts. Binomial generalized linear models connect disease prevalence with workspace, employment history and other covariates.

## Explore the project

| File | What it contains |
| --- | --- |
| [R Markdown analysis](Project.Rmd) | Data preparation, exploratory plots, candidate models and interpretation. |
| [Rendered analysis](Project.pdf) | Readable results with tables, figures and model output. |
| [Grouped observations](Byssinosis.csv) | Counts used in the analysis. |

## Data and use

The data and R Markdown source are kept together to preserve the original relative input path.
