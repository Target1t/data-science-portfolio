# Futures Order Flow and Market Microstructure

Evolution Labs quantitative research internship. The notebooks work with futures bid, ask and transaction sequences to construct order-flow imbalance signals, smooth them over time and study signal performance.

## Explore the project

| File | What it contains |
| --- | --- |
| [Order-flow imbalance](notebooks/order-flow-imbalance.ipynb) | Signal construction, exponential weighting and bid/ask-aware evaluation. |
| [Order-book signals](notebooks/order-book-signals.ipynb) | Depth- and range-based signal experiments and performance evaluation. |

## Data and use

These are research and replication notebooks from the internship. All cell sources are preserved. Saved cell outputs and the underlying tick-level feed are excluded.
