# Global Space Exploration Data Visualization

An exploratory visualization project examines the mix of technologies used in space missions and patterns of collaboration across countries.

## Explore the project

| File | What it contains |
| --- | --- |
| [Visualization notebook](analysis/space-exploration.ipynb) | Country collaboration matrices and comparisons of technology use. |
| [Project input](data/Global_Space_Exploration_Dataset.csv) | The mission dataset referenced by the notebook. |

## Data and use

The original notebook reads the CSV from its historical local path. The same input is included in the data directory.
