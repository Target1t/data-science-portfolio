# Relational Database Design for a University Running Club

A team project models the activities, members and operations of a university running club. Its SQL schema, role-specific views and diagrams document the relationship between operational requirements and the implemented database.

## Explore the project

| File | What it contains |
| --- | --- |
| [Database schema](sql/schema.sql) | Table definitions, primary keys and relational constraints. |
| [Member views](sql/member-views.sql) | The member-facing interface to the data model. |
| [Administrator views](sql/admin-views.sql) | Administrative reporting views. |
| [Editable ER diagram](design/entity-relationship.drawio) | Entity structure for the club database. |
| [Editable data flow diagram](design/data-flows.drawio) | Processes and information flows. |

## Data and use

SQL files contain schema and view definitions. Member records and database insert dumps are excluded.
