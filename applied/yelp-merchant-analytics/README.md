# Yelp Reviews, Social Networks and Merchant Performance

A course project uses review text, user connections and merchant attributes to study business performance. It brings together sentiment and topic analysis, network statistics and regression models for a merchant success index.

## Explore the project

| File | What it contains |
| --- | --- |
| [Analysis notebook](analysis/merchant-analysis.ipynb) | TF-IDF, VADER, topic modeling, NetworkX and gradient boosting. |
| [Project report (Chinese)](report/merchant-analysis.pdf) | Research questions, results and interpretation. |

## Data and use

The notebook expects local Yelp review, business and user tables. The portfolio preserves all cell sources and omits the saved outputs containing user and review identifiers.
